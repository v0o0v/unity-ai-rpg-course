# 개정13 검토·수정 보고서

**현재 판정: 검토 후보 — 최종 합격 아님**  
검토일: 2026-09-26

이번 자료는 최신 개정12판을 원본으로 보존하고 실제 요청·설명·화면·참고 코드를 대조해 수정한 결과입니다. 요청한 비평가 서브에이전트는 시작되지 않았습니다. Chat On Steroids Core의 연결 상태 확인을 세 번 시도했으나 모두 HTTP 404 `tunnel_client_not_seen`으로 실패했습니다. 아래 비평은 작성 에이전트의 자체 검토이며 독립 심사로 표시하지 않습니다.

## 1. 엄격하게 보면 기존 자료가 부족했던 지점

많은 페이지와 긴 해설이 곧 따라 할 수 있는 학습 경험을 보장하지 않았습니다. 첫 페이지부터 프로젝트 생성에 다운로드·캐시 이유가 연결되어 있었습니다. 실제 복사 요청에는 잘린 퀘스트 문장, 없는 작업표 경로, 등록하지 않은 역할의 호출이 남아 있었습니다. 데이터에 존재하는 상세 규칙 164개는 웹 읽기 화면에서 표시되지 않았습니다.

그래서 기존 자료를 ‘그대로 따라가면 충분히 배울 수 있다’고 최종 승인할 근거가 없습니다. 이번 수정은 그 부족함을 줄인 것이지, 문서나 로컬 테스트 수로 학습 성과를 증명한 것이 아닙니다.

## 2. 변경의 원칙

수강생은 목표와 예외를 말하고, AI가 파일·코드·설정·명령·검사를 수행합니다. 사람은 초기 앱 설치·로그인·권한/비용 결정·기기 연결·실제 플레이를 맡습니다. 요청에는 강의 번호나 숨겨진 교재 계약을 넣지 않습니다. 상세 그림·기술 해설·문장별 이유와 다크 모드는 보존합니다. 없어진 조건을 ‘통과’로 만들거나 실제 테스트의 조건을 낮추지 않습니다.

256개 페이지와 331개 기술 해설을 유지했습니다. 기존 실습 요청 1,536개 중 13개를 필요한 범위에서 수정했고 나머지 1,523개는 원문을 보존했습니다. 해설은 444개 항목을 고쳤습니다. 93개는 특정 문장의 의미를 직접 교정한 것이고, 351개는 제목·재개 문장의 작업 식별 의도를 바로잡은 것입니다. 이 수치를 444개의 독립 게임 결함이나 전체 해설 심사 완료로 해석하면 안 됩니다.

## 4. 수강생이 읽는 화면

목표 아래에 네 항목의 짧은 기능 흐름을 남기고, 전체 그림과 용어 목록은 필요할 때 펼치도록 바꿨습니다. ‘현재 메시지·그림·구체적인 예·값/규칙·막힘 진단’으로 바로 이동합니다. 긴 프롬프트의 굵은 요청과 이유는 유지하며, 요청문만 복사됩니다. 복사·그림 열기·키보드 탭 이동은 완료 체크를 바꾸지 않습니다.

첫 페이지의 만들기 단계 패널 시작은 같은 1440×1000 시험 화면에서 기존 약 1,517px 아래에서 수정본 약 770px 아래로 이동했습니다. 이는 그 화면에서 측정한 배치값이며 사용자의 글꼴·브라우저에 따라 다릅니다. 학습 시간이나 이해도 개선을 실험으로 측정한 수치는 아닙니다.

핵심 63개 페이지에는 ‘시작 상태→행동→정상 결과→실패 예→확인 질문/해설’을 추가했습니다. 하네스 제작 105~128은 모든 단계에 해당 예제가 있습니다. 이 외 페이지에도 기존 목표·관찰 동작·문장 해설과 전체 공통 진단을 유지했습니다. 256개 모두가 새 정밀 예제를 가진다고 주장하지 않습니다.

40·80·128·160·256에는 준비된 정답 프롬프트 없이 자기 요구·예외·보존할 조건을 정하는 과제를 넣었습니다. 코드 작성은 AI가 맡습니다. 전이 능력의 실제 통과 여부는 아직 시험하지 않았습니다.

## 5. 구조·문장·문맥 검사의 구분

모든 256개 페이지의 네 단계가 렌더링되고, 요청의 문장 범위가 원문 전체를 빠짐없이 가리키는지는 자동으로 검사할 수 있습니다. 그러나 해설이 정말 쉬운지, 모든 개념이 충분한지, 초보자가 막히지 않는지는 같은 검사가 증명하지 못합니다.

이번 정독은 처음 연결, 2D 이동·전투·저장·랜덤맵, 전체 하네스 제작, 첫 확장 작업, AI 퀘스트 도구, 저장·프로파일링의 연결 지점에 집중했습니다. 전 범위의 제목·목표·선행 상태·입출력 구조도 대조했습니다. 남은 모든 문장의 의미까지 독립 전문가가 승인한 결과가 아닙니다. 중복 설명은 동일 요청에 대한 공통 이유인 경우도 있으므로 반복 빈도 자체만으로 삭제하지 않았습니다.

## 6. 이번에 실행한 검사

구체적인 최종 수와 파일 해시는 함께 제공하는 `자료_검사_범위.md`와 JSON/로그를 기준으로 합니다.

- 문서·데이터 회귀: 33개 검사 함수. 내부 반복으로 256개 페이지·1,536개 실습 요청·331개 용어·문자 범위·출력 파일·규칙·참고 코드 보존을 대조합니다. 반복한 자료 건수를 독립적인 테스트 수로 더하지 않습니다.
- 기존 Python 참고 코드: 하네스 운영 77개, 누적 제작 73개, 실제 파일 연결 32개, 게임 보조 도구 17개 — 합계 199개를 현재 묶음에서 실행했습니다.
- GrayOath 퀘스트 참고 처리기: 46개 Python 검사. 실제 C#·Quest Editor와 별개입니다.
- 브라우저: 전체 1,024개 실습 단계의 렌더·문장 범위와 상호작용 시나리오를 검사합니다. 복사 원문, 원문 보기, 그림 확대, 용어 왕복, 331개 용어 화면, 다크 모드, 390px 모바일, 기록 가져오기·실제 파일 내보내기, 키보드 이동을 포함합니다.

화면 검사 중 자체 코드의 잘못된 펼침 동작을 발견해 수정했습니다. 정적 검사 중에는 ‘아트 자산과 다른 승인’이라는 비교 문장이 단어 기반 부정 검사에 걸렸습니다. 오류를 숨기지 않고 기존 로그를 보존했으며, 학습에 불필요한 비교 문장을 제거해 실제 설치 목적만 설명하도록 다듬었습니다.

|---|---|---|
| 독립 비평가 심사 | **BLOCKED** | 연결 복구 후 실제 worker의 별도 판단과 재심 |
| 모든 문장 해설의 독립 의미 검수 | **PARTIAL** | 전체를 담당 범위별로 읽은 목록과 반례, 미확인 범위 |
| 실제 Claude·Unity 연결 | **NOT RUN** | 실제 설치본의 명령과 모델 응답, 컴파일·씬·저장 결과 |
| Windows·Android 완주 | **NOT RUN** | 각각의 실제 빌드·입력·저장·엔딩·기기 결과 |
| 초보자 단독 진행과 전이 과제 | **NOT RUN** | 다른 설명 자료나 수동 개발에 의존하지 않은 관찰 기록 |
| 유료 아트·클라우드 배포 | **NOT RUN** | 사용자 승인 후 실제 서비스 요청·실제 파일·업로드 결과 |

이 조건들을 문서 개선이나 Python/브라우저 PASS로 대체하지 않습니다. ‘출시 가능’, ‘부족함이 없음’, ‘독립 심사 통과’라는 결론은 내리지 않았습니다.

## 8. 독립 재심 때 사용할 기준

재심자는 수정량·페이지 수·테스트 수가 아니라 실제 요청과 현재 읽기 화면을 봅니다. 다른 에이전트가 고쳤다는 설명을 신뢰하기 전에 첫 연결, 각 중간 관문, 121→125, 129→133, 185→196과 최종 전이 과제를 직접 대조합니다. 발견한 문제는 원문 위치와 입력·기대·관찰 차이로 남깁니다. 독립 검토자는 교재를 고치지 않고 별도 의견을 먼저 제출합니다. 작성자가 수정한 뒤 새 소스 해시에서 다시 심사합니다.

합격을 미리 목표 점수로 유도하지 않습니다. 미실행은 미실행으로 남깁니다. 실제 학습 성과까지 요구한 최종 목표는 초보자의 수행 증거가 필요하며, 연결 오류가 해결되기 전에는 독립 심사를 했다고 보고하지 않습니다.
