# AI가 설치·연결할 스킬 초안

학생은 파일을 직접 설치하지 않습니다. 로컬 AI에게 실제 .claude/skills와 현재 세션 지원을 조사·병합·설치·로드 검증하게 합니다. 기존 스킬과 설정을 덮어쓰지 않습니다. 이 폴더에 파일이 있다는 사실만으로 스킬이 활성화된 것은 아닙니다.

훅은 기존 하네스의 SessionStart/도구 후/Stop 지원과 실제 schema를 확인한 뒤 후보/증거 상태를 읽는 보조 경로로 연결합니다. 이 자료는 임의 settings.json을 학생이 붙여넣게 하지 않습니다. 긴 Unity build·유료 모델 생성·공개 게시를 훅에서 자동 실행하지 않습니다.

Editor 도구 버튼도 같은 command service와 후보 승인 경로를 씁니다. UI와 자연어 요청이 따로 구현되어 서로 다른 결과를 내지 않도록 동일 requestId·version·schema를 사용합니다.
