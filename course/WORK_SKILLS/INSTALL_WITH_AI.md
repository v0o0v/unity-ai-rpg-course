# 실제 작업 공간에 연결하는 절차

AI가 현재 로컬 Claude Code 버전과 공식 Skills/Hooks 문서를 확인한다. 프로젝트의 기존 .claude 설정과 실제 작성 하네스 경로를 읽는다. 템플릿에서 요청에 필요한 스킬만 현재 기능에 맞춰 생성하고 기존 설정과 충돌을 검토해 병합한다. 없는 프로그램을 스킬이 호출하게 만들지 않는다.

스킬 이름은 명시적 호출과 자연어 문맥으로 사용할 수 있지만 실제 환경의 선택·로드를 확인해야 한다. 설정 파일 작성, 지원 경로 탐색, 권한 설정과 테스트 실행은 AI가 맡는다. 사용자에게 슬래시 명령·셸·JSON 작성 과제를 주지 않는다.

훅은 별도로 현재 작성본에 생성한다. 세션 시작은 상태 안내, 도구 실행 전은 알려진 경로 확인, 실행 후는 재검사 필요 알림, 종료는 누락 안내로 제한한다. 실행 상태는 실제 run·후보·증거에서 계산한다. 훅 안에서 유료 모델·전체 빌드·자동 권한 승인·무한 재호출을 수행하지 않는다. 실제 세션에서 로드·발동이 확인되기 전 활성화 완료라고 말하지 않는다.

게임 후보를 바꾸면 현재 프로젝트·run·원본·스킬·훅 경로를 다시 확인한다. 인증이나 설정 폴더 전체를 무작정 복사하지 않는다. 참고 완성 하네스를 대신 실행해 성공을 꾸미지 않는다.
