현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

Grok/xAI의 이미지 생성·참조 편집으로 2D 게임 아트 후보를 만들어 줘. 현재 공식 모델·지원 형식·자동화 경로·비용을 확인하고 승인받은 범위만 실행해 줘.
회색 갑옷·청록색 망토·오른손 검의 기준 모험가를 확인받은 뒤 같은 참조로 남쪽 걷기와 공격 포즈를 만들어 줘. 근접병과 석재 타일은 별도 요청으로 나눠 줘.
시트의 셀 정렬·배경 제거·프레임 수가 자동으로 정확하다고 가정하지 마. 원본을 보존하고 64×64 RGBA, 발 (32,56), 캐릭터 PPU32·타일 PPU64로 정리해 줘.
생성·원본 수신·후처리·Unity 연결을 직접 수행하고 실제 알파·검 손·얼굴·발 위치를 검사해 줘. ArtLab2D의 동작 재생과 타일 반복판으로 보여 줘.
연결된 도구가 없으면 생성하지 않은 상태로 진단해 줘. 비밀키는 프로젝트·로그·배포물에 넣지 말고 실제 비용과 미지원 기능을 구분해 줘.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
