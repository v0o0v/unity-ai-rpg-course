내 하네스에 대화 밖의 상태 저장을 추가해 줘. 요청 ID, 요구 원문, 작업 상태, 마지막 정상 결과, 시도와 오류를 저장하되 게임의 플레이 저장과 분리해 줘.
정해진 형태의 JSON 읽기·검증·정규화·SHA256 지문과 임시 파일 기록 후 안전한 교체를 구현해 줘. 키 순서만 달라진 같은 데이터는 같은 논리 지문이어야 해. 비정상 숫자·깨진 JSON·누락 필드는 거부해 줘.
저장 중 실패해도 이전 정상 파일을 보존하고 손상 파일을 성공 초기 상태로 덮어쓰지 마. 원자 교체와 전원 장애에 대한 실제 내구성 보장은 구분해 줘.
game-status 스킬이 실제 상태를 읽어 한국어로 요약하도록 연결해 줘. 조회만으로 새 작업을 시작하거나 모델을 추가 호출하지 마.
정상 저장·재실행·키 순서 변경·값 변경·손상·저장 실패를 격리 사본에서 시험하고 실제 결과를 보여 줘.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.
