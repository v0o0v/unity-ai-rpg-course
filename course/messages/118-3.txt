현재 구현한 “모의 응답 대신 실제 Claude 연결하기”의 자동 검사와 도구 결과 화면을 준비해 줘. 정상 동작과 아래 실패 조건을 실제로 검사하고 대상·실행 수·결과를 보여 줘.

모델 불일치와 응답 형식 오류를 잡는다.

 승인 전 유료 호출을 시작하지 않는다.

 비용 미상을 0으로 적지 않는다.

 역할 호출에서 주 세션 훅을 중복 재귀 호출하지 않는다.

내가 조작해야 하는 부분은 실행할 화면과 시작 상태를 준비해 줘. 연결되지 않은 기기의 검사나 사람이 보지 않은 재미·소리 품질을 대신 확인했다고 하지 마. 테스트 0개와 예전 소스 결과는 현재 성공으로 쓰지 마.
