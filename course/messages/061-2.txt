현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

Ludo.ai의 스프라이트 제작 경로로 캐릭터 동작을 만들어 줘. 현재 모션 프리셋·키 포즈·참조 동작·내보내기 기능과 API 또는 승인된 자동화 연결을 확인해 줘. 웹 구독과 API 비용을 구분해 승인받아 줘.
현재 승인된 모험가 기준 그림을 사용하고, 없으면 회색 갑옷·청록색 망토·오른손 검의 기준 그림부터 확인받아 줘. 걷기와 준비→타격→회수의 공격을 별도 생성해 줘.
64×64 RGBA 남쪽 걷기 6프레임·공격 6프레임으로 시작해 줘. 출력의 실제 프레임 수·투명도·트리밍·프레임 위치 정보를 읽고 발 기준을 맞춰 줘.
생성·수신·정리·Unity 연결은 직접 수행해 줘. 시트를 받지 못했다면 임의 경로를 만들지 마. 원본과 비용을 남기고 ArtLab2D에서 걷기와 공격을 반복 재생해 줘.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
