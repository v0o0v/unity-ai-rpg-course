내 하네스로 기존 게임의 사본에 작은 LootPreviewLab2D 장면을 만들어 줘. 원래 마을·던전·저장은 유지해 줘.
일반·마법·희귀 장비 각각 하나와 이름표·실제 줍기 대상을 배치해 줘. 현재 게임의 아이템 인스턴스·드롭·상호작용 규칙을 쓰고 별도 모의 인벤토리로 바꾸지 마.
기획·구현·QA·Unity 통합·독립 검토 역할을 필요한 순서로 사용해 줘. C# 변경안과 Editor API 통합을 구분하고 승인한 후보에서만 장면을 생성해 줘.
컴파일·실제 EditMode 검사·Play 화면을 각각 확인해 줘. 생성기를 두 번 실행해도 오브젝트가 중복되지 않게 해 줘. 세 아이템을 줍는 화면을 내가 확인할 수 있게 열어 줘.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.
