실제 검사 결과를 검사한 후보 소스와 묶는 증거 계층을 만들어 줘. 소스 파일 목록과 내용 지문, 계획·명령·대상 플랫폼, 실행 시각, 결과 파일 지문, 실제 검사 수를 기록해 줘.
현재 소스와 증거의 기준이 다르거나 결과 파일이 바뀌면 이전 성공을 현재 성공으로 쓰지 마. 빈 증거 목록과 비활성 검사를 사람의 확인으로 통과시킬 수 없게 해 줘.
도구 실행 후 훅은 변경 가능성을 알릴 뿐, 최종 판정은 현재 소스 전체와 증거를 다시 읽어 계산하게 해 줘. 실행 기록과 대시보드 파일은 소스 지문 계산에서 분리해 줘.
작은 후보의 테스트를 실제 실행한 뒤 코드·증거 사본을 바꾸어 오래된 결과가 거부되는지 확인해 줘. 재검사 후에만 새 결과를 인정해 줘. 컴파일·기능·사람 플레이는 서로 다른 검사로 남겨 줘.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.
