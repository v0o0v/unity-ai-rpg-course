콘텐츠 검수 담당을 새 역할로 추가해 줘. 기존 기획·구현·QA·검토의 책임과 겹치는 부분을 먼저 찾아 좁혀 줘.
새 역할은 아이템·퀘스트 정의와 참조를 읽고 문제 목록을 제출하게 해 줘. 게임 코드·원본 자산·검사 결과를 직접 수정하는 권한은 주지 마.
등록 데이터만 추가한 것으로 끝내지 말고 계획 검증·입력 준비·공급자 요청·응답 검증·독립 검토까지 연결해 줘. 역할 ID 중복·필수 입력 누락·권한 확대 요청을 거부해 줘.
실제 작은 콘텐츠 검수 작업을 실행하고 새 역할의 제안이 어디로 이어지는지 보여 줘. 실제 모델을 호출하려면 기존 승인 한도 안인지 확인해 줘.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.

콘텐츠 검수 역할을 검증한 다음 Unity 통합 역할 unity_integrator도 별도로 등록하고 시험해 줘.

unity_integrator는 승인된 후보의 Editor 통합 코드만 제안하고, 실행은 등록된 Unity 명령 창구가 담당하게 해 줘.

역할별 입력·후보 쓰기 범위·금지 행동·독립 검토자를 기록하고, 미등록 역할·원본 수정·검사 약화 요청이 거부되는지 확인해 줘.
