내가 만든 하네스의 실제 경로와 현재 게임 후보를 확인하고 game-feature로 이 작업을 처리해 줘. 필요한 담당 역할만 고르고 구현·QA·독립 검토를 분리해 줘. 변경안·승인한 후보·Unity 통합·현재 소스 검사를 실제로 연결하고, 참고 완성본으로 우회하지 마.

기존 세 스킬의 기본형/변형형 선택을 추가해 줘. 9노드 트리와 포인트 총량은 유지해 줘.
마을에서 배운 스킬에만 선택을 허용하고 스킬이 잠기면 기본형으로 정리해 줘.
선택 변경으로 마나·체력·쿨다운을 회복하지 마.
범위·피해·비용·VFX 데이터는 한 계산 결과를 사용하고 실행 중 다시 읽지 않게 해 줘.
아래 초기 변형 수치와 룬/표식의 적용 순서를 표와 테스트로 고정해 줘.

이 기능의 규칙:
기존 스킬트리를 다시 만드는 대신 배운 스킬마다 기본형 또는 변형형 하나를 고른다. 베기는 범위를25% 넓히는 대신 직접 피해15% 감소, 마력탄은 첫 유효 적중 대상에 표식을 남기는 대신 마나 비용20% 증가, 회전은 이동 감속을 줄이는 대신 지속시간20% 감소로 시작한다. 전부 이득인 강화가 아니라 역할이 달라지는 선택이다.

변형 선택은 마을에서만 가능하고 배운 스킬에만 적용한다. 포인트를 초기화해 스킬이 잠기면 해당 선택은 기본으로 정리한다. 바꾸는 동안 현재 마나·체력·쿨다운은 회복하지 않는다. 소비 마나의 반올림 규칙을 공통 계산 함수로 통일한다.

베기 넓이가 바뀌면 실제 부채꼴과 효과 범위도 같은 데이터로 바뀌어야 한다. 공격 도중 선택이 바뀌는 상황은 마을 제한으로 막고, 실행 시작 시 확정한 스킬 스냅샷을 끝까지 사용한다. 룬·표식·변형 피해의 적용 순서를 문서와 테스트에 고정한다.

초기 변형은 베기: 최종 반경×1.25·계수×0.85, 마력탄: 마나비용×1.2·명중 뒤 표식 적용, 회전: 지속시간×0.8·이동 비율+0.20(최대1)로 해 줘. 마나비용은 마지막에 올림, 회전은 0.25초마다 만료 시각 이하의 틱만 실행해 1.6초에서는 6틱이다. 현재 타격에는 새 표식을 적용하지 않는다. 이 수치를 실제 계산·UI·테스트에 함께 사용해 줘.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
