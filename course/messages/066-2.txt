현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

현재 2D 랜덤맵에 자동 타일링과 선택한 타일 아트를 연결해 줘. 기본은 직사각형 타일맵으로 유지해 줘.
북1·동2·남4·서8의16개 경계 마스크와 누락 시 대체 타일을 만들고 실제 테스트 보드를 보여 줘. 장식 변형은 장식 시드와 셀 좌표만 사용하고 지도·전리품 난수는 소비하지 마.
큰 벽 그림과 실제 차단 셀을 분리하고 A*·몸체 반경·스폰은 보존해 줘. 3×3 반복 이음새, 마스크16개, 생성 시드100개의 매핑 누락과 실제 앞뒤 정렬을 검사해 줘.
아이소메트릭 표현은 내가 별도로 요청할 때만 사본에서 선택 작업으로 진행해 줘. 격자 변환·클릭·발 정렬·방향 속도를 함께 검사하고 기본 게임에 자동으로 합치지 마.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
