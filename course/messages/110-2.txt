검증한 계획을 시작하는 실행 저장소와 역할별 입력 묶음을 만들어 줘. 실행마다 고유 run ID와 새 폴더를 만들고 원본·계획·역할 설정의 지문을 고정해 줘.
역할에게는 요구, 완료 조건, 명시한 읽기 파일, 필요한 선행 결과만 전달해 줘. 누락된 파일과 너무 큰 입력은 조용히 생략하지 말고 작업 분할이나 재조사로 돌려 줘. 비밀 파일은 전달하지 마.
각 시도의 입력·응답·오류·시작과 종료를 별도 보존하고 끝난 기록을 덮어쓰지 마. 재개할 때 계획과 원본이 바뀌었는지 검사해 줘.
세션 시작 훅에는 실제 실행 상태의 위치와 재개 필요를 알려 주는 짧은 동작만 연결해 줘. 세션이 시작됐다는 이유로 유료 호출이나 Unity 빌드를 시작하지 마.
누락 입력·입력 변경·중복 run 경로·중단 후 조회를 실제로 시험해 줘.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.
