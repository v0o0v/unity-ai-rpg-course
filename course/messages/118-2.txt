내 하네스의 공급자를 실제 Claude Code 호출로 확장해 줘. 설치본의 공식 도움말에서 비대화형 실행·구조화 출력·모델·권한·시간과 비용 제한을 먼저 확인해 줘.
요청 모델은 claude-opus-5-5다. 실제 응답의 모델 정보와 오류·권한 거부·구조화 결과·사용량을 검사해 줘. 모델을 바꾸거나 안전 옵션을 우회해 성공시키지 마.
주 세션은 스킬로 도구를 운영하지만 격리된 역할은 명시한 자료를 읽고 변경안만 반환하게 해 줘. Edit·셸·MCP·하위 위임 등의 권한은 역할에 자동 상속하지 마. 현재 CLI에서 강제 가능한 설정을 확인하고 불가능한 경계는 설명해 줘.
구독 로그인과 API 키 경로를 구분해 줘. 비밀키를 코드·프롬프트·로그에 쓰지 마. 실제 호출 전 모델·최대 호출 수·예약 비용·시간 제한을 보여 주고 승인받아 줘.
작은 한 역할 호출부터 실행해 실제 응답을 검사한 뒤 모의 공급자와 동일한 실행기 경로로 연결해 줘. 비용을 모르면 0원으로 기록하지 마.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.
