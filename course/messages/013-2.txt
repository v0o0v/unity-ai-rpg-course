현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

기본 공격을 Physics2D와 ActorRoot XY 좌표로 구현해 줘.
반경1.8, 전방90도, 간격0.7초, 타격시점0.2초다. 같은 attackSequenceId/actorId는 한 번만 피해를 줘.
OverlapCircle로 후보를 모으고 거리/내적/Environment Linecast/생존을 타격 시점에 확인해 줘.
PC는 적 클릭→A* 접근→공격,Android 는 자동 접근 없이 전방선택 또는 헛스윙이다.
자식 Hurtbox 두 개가 같은 Actor에 속하면 중복을 제거해 줘.
피해 권한은 타이머 한 곳이고 Sprite 프레임과 Animation Event는 표시만 해 줘.
36→24, 벽뒤피해0, 두콜라이더도12피해, 중간사망/씬 전환 취소를 실제 검사해 줘.
3D Collider나 Physics.OverlapSphere를 추가하지 마.

적용할 세부 규칙:
기본 공격 간격0.7초, 타격시점0.2초, 반경1.8, 전방90도, 공격력12로 시작한다. 적 HP36이면 첫 타격 후24다. 후보는 Physics2D.OverlapCircle 계열로 모으고 XY 거리·Facing과의 내적·Environment Linecast로 거른다. 시각적 Sorting Layer 순서는 타격 여부를 결정하지 않는다.

PC는 적을 클릭하면 유효 접근 waypoint를 선택해 사거리 안에서 공격한다. Android 는 자동 접근하지 않고 가까운 전방 적을 선택하거나 헛스윙한다. 표적이 사망·사거리이탈·벽뒤로 이동하면 타격 시점에 다시 검증한다. 적 클릭은 ActorRoot뿐 아니라 자식 Hurtbox에서 소유 Actor ID를 찾는다.

논리적으로 칼이 벽을 무시하지 않게 LOS는 발 기준의 2D 벽으로 검사한다. 그림의 머리 위치에서 쏘는 3D ray를 사용하지 않는다. 피격 이펙트 위치는 별도의 표시점일 수 있다.
