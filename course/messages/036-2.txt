현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

Android 가로 전용 UI와 생명주기를 실제 기기 기준으로 마무리해 줘.
SafeArea 안에 HUD·조이스틱·버튼을 배치하고 양쪽 가로 회전을 지원해 줘.
실제 터치 영역은 이미지보다 작지 않게 하고 주요 버튼 간 간격을 확보해 줘.
초기 참고값은 공격168/스킬144/보조128 reference-unit이지만
화면 스케일 후 실제 크기를 검사하고 기기별 UI scale 옵션으로 조정해 줘.
조이스틱과 공격/스킬/물약이 서로 다른 pointerId로 동시에 동작해야 해.
OnApplicationPause(true)와 focus 상실에서 입력·선택·진행 스킬을 정리하고
검증된 현재 상태 저장을 요청해 줘. 동시에 여러 저장을 실행하지 마.
복귀 시 회전 공격 이동속도, 일시정지 상태, 오디오,UI 잠금을 정확히 복구해 줘.
Android Back은 열린 상세창/인벤토리/대화창을 먼저 닫고 그다음 일시정지 메뉴를 열게 해 줘.
가방 선택은 hover 없이 가능해야 하고 아이템 근접 상호작용을 제공해 줘.
조이스틱을 누른 손가락을 놓는 위치가 달라도 stuck input이 없어야 해.
실기기 미연결이면 자동으로 PASS 를 만들지 말고 기기 연결·USB 디버깅 승인 등 사람이 필요한 관문과 AI가 수행할 설치·로그·검사 절차를 나눠 보고해 줘.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
