현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

24칸 가방,3개 장비 슬롯, 아이템 상세 패널, 장착/해제/닫기 버튼을 만들어 줘.
PC I와 Android 인벤토리 버튼을 동일 UI 흐름에 연결해 줘.
기본 조작은 클릭/탭 선택 후 명시적 버튼이며 드래그 앤 드롭은 만들지 마.
선택한 아이템과 현재 장비의 실제 최종 수치 차이를 계산해 보여 줘.
색만으로 등급을 구분하지 말고 등급 이름과 옵션 줄도 보여 줘.
UI는 Inventory/Equipment의 명령을 호출하고 성공 이벤트를 받아 갱신하게 해 줘.
슬롯 이미지를 바꾸는 것으로 데이터를 바꾸지 마.
이번 게임은 인벤토리가 열리면 싱글플레이 전투를 일시정지한다.
UI 애니메이션/버튼은 unscaled time을 사용하고 게임 입력은 잠가 줘.
UI를 닫거나 앱 복귀할 때 held 입력을 초기화하고 timeScale/잠금 상태를 복구해 줘.
선택 아이템이 판매/삭제/장착으로 이동하면 상세 패널을 안전하게 갱신해 줘.
실제 데이터 변경, 긴 텍스트, 연속 열고닫기, 가득 찬 가방 실패 표시를 검증해 줘.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
