현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

현재 2D 게임의 Windows 와 Android 빌드를 각각 준비해 줘. 새 게임→마을 준비→던전→전리품→장비·스킬 투자→보스→보상→저장·재실행을 정상 입력으로 확인하고 싶어.
최초 오프라인, 선택 팩 없음, 랜덤맵 실패 복구, 이전 저장도 같은 현재 소스에서 검사해 줘. 개발자 순간이동·즉시 보상으로 완주를 대신하지 마.
자동 검사와 실제 PC·휴대폰 조작을 구분해서 기록하고 내가 확인할 화면과 시작 상태를 열어 줘. 기기나 계정이 없으면 해당 결과를 따로 남겨 줘.
완주 뒤 내가 정하는 작은 새 기능 하나를 별도 후보에서 계획·구현·검사해 줘. 기존 저장과 게임을 보존하고 실제 오류가 생기면 재현→수정→재검사 과정을 보여 줘.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
