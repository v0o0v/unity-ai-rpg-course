Unity의 씬·프리팹·참조·Play·검사 요청을 내 하네스의 전용 창구로 모아 줘. 프로젝트별 잠금과 등록된 명령만 쓰고 컴파일·도메인 리로드·미저장 씬·외부 변경을 확인해 줘.
씬·자산 연결은 현재 설치된 Editor API 로 실행하고 같은 생성 요청을 반복해도 중복되지 않게 해 줘. 역할 변경안이 .unity/.prefab/.meta를 직접 문자열로 쓰지 않게 해 줘.
같은 프로젝트를 GUI Editor와 별도 배치 Editor에서 동시에 열지 마. 요청 접수·실행 중·실제 완료·실패를 나누고 시간 초과 뒤 프로세스를 확인해 줘.
새 후보로 이동할 때 원본과 후보·run을 다시 연결하고, 검토한 프로젝트 스킬·훅만 기존 설정과 합쳐 실제 로드·발동을 확인해 줘. 세션 전체나 인증 설정을 무작정 복사하지 마.
통합 명령 성공과 게임 동작 검사는 별도로 기록해 줘.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.
