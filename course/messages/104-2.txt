현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

최종 검증을 진행해 줘.
2D/3D × Windows/Android 네 조합의 산출물과 실제 실행 여부를 먼저 확인해 줘.
새 게임→성장→장비→스킬트리→랜덤던전→저장/재실행→보스→퀘스트 보상을 각각 완주해 줘.
오프라인/캐시/첫 다운로드/취소/복구/잘못된 팩/저장 왕복을 구분해 줘.
실행할 수 없는 기기·서비스는 BLOCKED, 아직 실행하지 않은 검사는 NOT RUN으로 남겨 줘.
실패는 재현·원인·최소 수정·재검사까지 진행하고 관련 2D/3D 회귀를 확인해 줘.
실제 증거가 있는 결과만 최종 보고서에 PASS 로 기록해 줘.

적용할 세부 규칙:
• 조합: 2D Windows / 필수 흐름: 새 게임·클릭/WASD·전투·장비·스킬트리·랜덤맵·저장·보스·보상
• 조합: 2D Android / 필수 흐름: 위 흐름 + 실제 멀티터치·안전영역·앱 중단 복귀
• 조합: 3D Windows / 필수 흐름: 같은 흐름 + 실제 3D 경로·가림·모델·콘텐츠
• 조합: 3D Android / 필수 흐름: 같은 흐름 +3D 실기기 성능·다운로드·터치

각 조합에서 최초 실행 오프라인·캐시 있음·첫 다운로드·취소·재시작을 구분한다. 원격 서비스에 접근하지 못한 경우 기본 오프라인 완주와 원격 미검증을 분리한다.

최종 보고서에는 성공뿐 아니라 FAIL/BLOCKED/NOT RUN, 재현 절차, 남은 한계, 사용한 서비스/자산의 출처·비용을 기록한다. 예시 검사항목이 많다고 자동으로 게임 품질이 보장되지는 않는다.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
