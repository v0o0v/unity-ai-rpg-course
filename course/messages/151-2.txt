내가 만든 하네스의 실제 경로와 현재 게임 후보를 확인하고 game-feature로 이 작업을 처리해 줘. 필요한 담당 역할만 고르고 구현·QA·독립 검토를 분리해 줘. 변경안·승인한 후보·Unity 통합·현재 소스 검사를 실제로 연결하고, 참고 완성본으로 우회하지 마.

새 기능의 발견형 도감·장비 비교·첫 확장 튜토리얼을 추가해 줘.
비교는 실제 능력치 계산기를 가상 상태에 적용하고 실제 장비·자원·쿨다운을 바꾸지 마.
룬 포함 여부와 일시 유물 제외 여부를 화면에 분명히 표시해 줘.
아직 보지 않은 유물 제안이나 퀘스트 답을 도감에 누출하지 마.
튜토리얼은 건너뛰기·다시 보기를 지원하고 반복 보상을 주지 않게 해 줘.
실제 Android 화면과 초보 관찰에서 UI 발견성을 검증해 줘.

이 기능의 규칙:
기능이 많아지면 버튼이 있다는 사실만으로 찾기 어렵다. 확장 도감은 본인이 발견한 적 속성·재료·상태·룬·유물을 설명한다. 숨겨진 퀘스트 정답이나 아직 선택하지 않은 다음 유물 제안을 보여 주지 않는다. 해금 도감은 영구 진행, 현재 검색과 탭은 UI 상태다.

장비 비교는 현재 장비를 후보 장비로 바꾼 가상 상태에서 같은 능력치 계산기를 사용한다. 원래 장비의 룬 제거와 새 장비 룬 적용을 함께 반영하고 실제 장착·재료 차감·쿨다운 변경은 하지 않는다. 표식·유물 같은 임시 효과는 기본 비교에서 제외하되 포함 여부를 명시한다.

처음 구조한 대장장이가 필터→분해→제작→룬 순서의 짧은 안내를 제공한다. 한번에 긴 설명을 덮지 않고 현재 화면에서 다음 행동 한 개만 제시한다. 건너뛰어도 진행되고 설정에서 다시 볼 수 있다. 튜토리얼을 다시 열어도 보상이 나가지 않는다.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
