현재 PC에서 실제로 쓸 Unity 명령을 조사해 하네스에 등록하는 기능을 만들어 줘. Editor 실행 경로, CLI와 Pipeline 버전, 대상 프로젝트, 통합 메서드, 테스트 이름과 결과 위치를 확인해 줘.
설치본 도움말과 실제 프로젝트의 지원 명령을 바탕으로 인수 목록을 구성해 줘. 과거 예시의 옵션을 추측해 쓰지 마. 설정 생성과 실행은 직접 맡아 줘.
먼저 읽기 전용 ProjectProbe를 실행한 뒤, 등록한 테스트 하나가 실제로 발견되고 결과 파일을 새로 만드는지 확인해 줘. 0개 테스트는 실패야.
GUI와 배치 실행의 프로젝트 점유를 구분하고 필수 명령이 없으면 그 검사만 막힘으로 표시해 줘. 가짜 결과 XML이나 예전 로그를 현재 실행 결과로 쓰지 마.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.
