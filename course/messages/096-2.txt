현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

3D 카메라·가림·모바일 조작을 다듬어 줘.
입력은 카메라 수평 right/forward로 XZ에 변환하고 대각선 크기를 제한해 줘.
가림 처리는 Renderer에만 적용하고 Collider/NavMesh/피해 LOS는 변경하지 마.
공유 Material 전역 변경과 원복 누수를 방지해 줘.
기본 사선 Orthographic를 유지하며 Android 에서 플레이어·예고·버튼이 읽히는지 확인해 줘.
UI 소비·멀티터치·화면 밖 포인터·Pause·씬 왕복을 실제 검사해 줘.

적용할 세부 규칙:
기본 카메라는 사선 Orthographic를 유지한다. 추적은 LateUpdate에서 하고 이동 모터는 기존 주기로 동작한다. 먼 적을 보기 위해 카메라를 무조건 멀리 빼면 Android 캐릭터가 너무 작아지므로 실제 화면의 몸체 크기·버튼 영역을 함께 본다.

가림 감지는 EnvironmentVisual 전용 레이어를 사용한다. 가까운 벽의 Renderer만 투명화/잘라내기 처리하고 Collider·NavMesh·피해 LOS는 유지한다. 공유 Material을 직접 바꿔 모든 벽이 투명해지지 않도록 개별 속성과 원복 수명을 관리한다.

같은 포인터로 UI를 누른 뒤 배경을 공격하지 않게 UI 소비 규칙을 유지한다. 왼손 이동+오른손 공격, 손가락 화면 밖 이동, 앱 Pause에서 입력 상태를 검사한다.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
