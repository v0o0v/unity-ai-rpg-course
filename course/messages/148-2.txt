내가 만든 하네스의 실제 경로와 현재 게임 후보를 확인하고 game-feature로 이 작업을 처리해 줘. 필요한 담당 역할만 고르고 구현·QA·독립 검토를 분리해 줘. 변경안·승인한 후보·Unity 통합·현재 소스 검사를 실제로 연결하고, 참고 완성본으로 우회하지 마.

봉인된 대장간의 신규 적2변형·드론·보스·타일·룬 아이콘 제작 요청을 역할별로 작성해 줘.
기존 ART_BIBLE과 실제 원본의 PPU·피벗·방향을 읽고 결과 규격을 고정해 줘.
기본 harness가 PNG를 직접 생성하거나 봤다고 주장하지 마. 외부 제작과 시각 관찰을 별도 승인·증거로 기록해 줘.
채택한 자산만 기존 외형 연결부에 도입하고 Collider2D와 전투 수치는 유지해 줘.
서비스를 전부 결제하지 말고 선택 경로 하나와 무비용 placeholder 경로를 구분해 줘.

이 기능의 규칙:
이 작업은 서비스를 다시 소개하는 장이 아니라 이미 배운 제작 경로를 역할별 산출물로 사용한다. 아트 디렉터는 기존 스프라이트의 PPU·방향·실루엣·색 대비를 확인하고, 제작 역할은 방패병·화염술사·드론·감시자·대장간 타일·룬 아이콘의 배치 규격을 만든다. 실제 생성은 내가 선택하고 승인한 제작 경로를 사용한다.

기본 하네스는 텍스트만 입력하고 PNG 바이너리를 직접 수정하지 않는다. 아트 역할이 결과 파일을 만들었다고 JSON에 적었다고 이미지가 생기는 것은 아니다. 승인된 외부 도구 또는 사람이 원본을 생성하고, 파일 해시·출처·비용·제작 설정·채택 여부를 manifest에 남긴다. binary import는 검토한 통합 작업으로 한다.

사람 또는 별도로 구현한 시각 어댑터가 실제 원본을 본 경우에만 관찰을 기록한다. 텍스트 critic의 의견은 프레임 정렬·발 위치·다리 개수의 실제 확인이 아니다. 후보 이미지가 규격을 못 맞추면 placeholder를 유지하며 검증 상태를 분리한다.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
