현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

4방향 Sprite 애니메이션과 2D 효과음을 실제 전투에 연결해 줘.
Idle/Walk/Attack/Hurt/Dead 우선순위를 정의하고 마지막Facing을 보존해 줘.
애니메이션은 VisualRoot의Sprite참조만 바꾸며 ActorRoot/Collider2D를 키프레임으로 움직이지 마.
실제 이동량을 사용해 벽 앞 걷기 애니메이션을 판정해 줘.
기본공격0.2초의 단일 타격 권한을 유지하고 클립을 그 시각에 맞춰 줘.
공격/피격/물약/드롭/UI 소리의 중복과 동시재생 수를 제한해 줘.
Pause와Dead의전환, 마지막방향, 씬 종료 후남은소리를 검사해 줘.

적용할 세부 규칙:
우선순위는 Dead>Attack/Skill>Hurt>Walk>Idle로 시작한다. Hurt 표시 때문에 이미 확정된 게임 상태가 임의 취소되지 않도록 규격을 정한다. 걷기는 입력 크기 대신 실제 이동거리로 결정해 벽을 계속 밀 때 달리기하지 않게 한다.

4방향 S/W/N/E는 화면 아래/왼쪽/위/오른쪽이다. 정지하면 마지막 Facing을 유지한다. 방향 경계에서 작은 흔들림으로 프레임이 좌우로 교대하면 hysteresis를 넣는다. 일시정지 중 전투 애니메이션은 멈추고 UI 애니메이션만 unscaled time을 사용한다.

음향은 2D AudioSource로 시작한다. 같은 명중에 여러 소리가 겹치지 않게 eventId와 동시재생 한도를 관리한다. 외부 음원을 썼다면 사용 조건을 기록한다.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
