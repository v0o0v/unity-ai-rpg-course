하네스에 등록된 검사만 실행하는 프로세스 창구를 만들어 줘. 실행 파일과 인수 목록, 작업 디렉터리, 시간 한도, 결과 위치를 검토한 설정으로 고정하고 모델의 셸 문자열을 직접 실행하지 마.
stdout·stderr·종료 코드·시간 초과·실제 결과 파일을 보존하고 현재 플랫폼에서 실행 중인 프로세스를 정리하는 절차를 검사해 줘. 종료 요청을 보냈다는 이유만으로 실제 종료를 가정하지 마.
Python 테스트와 NUnit XML을 읽는 결과 파서를 만들어 줘. 최소 검사 수는 양의 정수로 강제하고 0개 실행·중복 테스트 ID·모순되는 성공/실패 요약·결과 누락·실패 종료를 거부해 줘. 서로 다른 실제 매개변수 테스트는 구분해 줘.
모의 역할이 만든 작은 후보의 테스트를 실제로 실행해 줘. 역할 응답은 모의이지만 테스트 프로세스는 실제 실행인지 분리해 보여 줘.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.
