역할 입력에서 실제 모델 요청문을 만드는 기능과 구조화 응답 검증기를 구현해 줘. 지금은 생성된 요청과 고정된 응답 파일로만 확인해 줘.
구현 응답은 작업 ID, 기준 입력 지문, 완료/막힘 상태, 변경 목록을 갖고 각 변경은 경로·기존 내용 지문·새 텍스트를 포함하게 해 줘. 조사와 검토 응답은 코드 변경 목록 없이 보고서를 제출하게 해 줘.
누락 필드·다른 작업 ID·기준 지문 불일치·권한 밖 쓰기·과도한 크기·금지 파일·검토자의 변경안을 거부해 줘. 모델이 제출한 경로나 권한·명령은 신뢰하지 마.
응답을 실행 코드나 셸 명령으로 바로 실행하지 말고 검토 가능한 변경안으로 저장해 줘. 정상·빈 응답·잘못된 JSON·문장으로만 된 완료 보고를 실제로 검사해 줘.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.
