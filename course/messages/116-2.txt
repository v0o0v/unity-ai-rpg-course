실제 실행 기록과 현재 후보에서 상태를 계산하는 game-status 스킬과 대시보드를 만들어 줘. 설명용 예시 상태 파일이나 참고 완성본을 대신 읽지 마.
구현 제안·검토 결과·실제 자동 검사·사람 확인·승인 대기·막힘을 분리해 보여 줘. 현재 run·후보·하네스의 경로를 확인하고 소스가 바뀌면 재검사 필요를 표시해 줘.
훅이 읽을 짧은 상태 요약도 이 실제 조회 결과에서 생성해 줘. 오래된 요약·다른 프로젝트·변조된 증거는 성공으로 재사용하지 마.
종료 훅은 필요한 검증을 알려 주되 승인 대기·사용자 중단·도구 미연결 상태에서 무한 반복을 만들지 않게 해 줘. 훅 안에서는 유료 모델·긴 빌드·자동 권한 승인을 실행하지 마.
“어디까지 됐어?” 요청이 새 작업 없이 현재 상태만 읽는지 확인해 줘.

현재 작성한 MyGameHarness를 확장하고 필요한 파일·테스트·스킬 연결을 직접 만들어 실행해 줘. 정상 예와 실패 예를 실제로 보여 주고, 기존 기능이 유지되는지 확인해 줘.
