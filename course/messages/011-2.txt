현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

현재 이동 테스트 공간을 Windows 와 Android 개발 빌드로 만들어 줘.
실제 연결된 Editor로 빌드할 수 있는 명령인지 Docs/UNITY_COMMANDS.md와 --help를 확인해 줘.
별도 batchmode 프로세스를 쓰려면 같은 프로젝트를 열고 있는 Editor와 충돌하지 않게 해 줘.
Windows x86_64 개발 빌드와 Android IL2CPP ARM64 테스트 APK를 분리해 줘.
초기 씬은 Boot이며 메뉴에서 TestArena에 진입할 수 있어야 해.
Windows 는 Builds/WindowsDev, APK는 Builds/AndroidDev에 저장해 줘.
빌드 보고서에 실제 경로, 종료 상태, 에러, 파일 크기, 사용 프로필을 남겨 줘.
연결된 Android 기기가 없거나 인증되지 않았으면 실기기 검증은 BLOCKED로 보고해 줘.
빌드만 성공한 것을 설치·플레이 성공으로 적지 마.
내가 확인할 PC 클릭/WASD, 모바일 두 손가락, 포커스 복귀 검사를 안내해 줘.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
