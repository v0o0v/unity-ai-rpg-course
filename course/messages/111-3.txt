현재 구현한 “AI 답변을 안전한 변경안으로 받기”의 자동 검사와 도구 결과 화면을 준비해 줘. 정상 동작과 아래 실패 조건을 실제로 검사하고 대상·실행 수·결과를 보여 줘.

입력이 다른 응답은 거부한다.

 검토 역할이 파일을 쓰려 하면 거부한다.

 모델 응답의 셸 명령을 실행하지 않는다.

 결과가 길어서 잘린 응답을 성공으로 처리하지 않는다.

내가 조작해야 하는 부분은 실행할 화면과 시작 상태를 준비해 줘. 연결되지 않은 기기의 검사나 사람이 보지 않은 재미·소리 품질을 대신 확인했다고 하지 마. 테스트 0개와 예전 소스 결과는 현재 성공으로 쓰지 마.
