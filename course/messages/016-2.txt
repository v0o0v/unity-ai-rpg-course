현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

물약과 플레이어 사망 흐름을 만들어 줘.
물약은 별도 수량 0..99, 시작 5개, 회복35, 쿨다운 1초로 해 줘.
만피·사망·수량0·쿨다운 중에는 소비하지 않고 이유를 UI 로 표시해 줘.
PC 1과 모바일 Potion이 동일 UsePotion 규칙을 호출하게 해 줘.
플레이어 사망 시 입력·이동·공격·스킬의 진행 작업을 취소하고 중복 사망창을 막아 줘.
TestArena에서는 다시 시작 버튼이 테스트 공간 스폰으로 이동시키고 HP/MP를 회복하게 해 줘.
완성 게임에서는 던전 사망→Town 복귀로 교체할 SceneFlow 접점만 준비해 줘.
골드·장비 손실이나 시체 회수는 추가하지 마.
재시작 전에 모든 held 입력, 대상 선택, 남은 공격 시퀀스, 화면 잠금을 초기화해 줘.
죽은 뒤 늦게 날아온 피해, 두 번 누른 재시작, 물약과 사망 동시 프레임을 검사해 줘.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
