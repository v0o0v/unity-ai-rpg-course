내가 만든 하네스의 실제 경로와 현재 게임 후보를 확인하고 game-feature로 이 작업을 처리해 줘. 필요한 담당 역할만 고르고 구현·QA·독립 검토를 분리해 줘. 변경안·승인한 후보·Unity 통합·현재 소스 검사를 실제로 연결하고, 참고 완성본으로 우회하지 마.

대장장이 구조→마을 복귀→대장간과 동료 해금→보스 보고의 새 퀘스트 체인을 추가해 줘.
기존3개 퀘스트는 보존하고 데이터 기반 짧은 분기 대화를 사용해 줘.
대화 선택을 다시 열거나 completion 이벤트를 반복해도 보상이 한 번만 저장되게 해 줘.
해금 상태로 NPC 출현을 복원하고 씬마다 NPC를 중복 생성하지 마.
필수 진행을 막는 영구 잘못된 선택은 만들지 마. 개발용 즉시 해금과 실제 플레이를 분리해 줘.

이 기능의 규칙:
새 퀘스트는 마을 소문→구조방 적 처치→대장장이 해방→마을 대장간 해금→새 보스 처치 보고로 이어진다. 기본 제작 기능을 먼저 구현했더라도 출시 빌드에서는 이 체인으로 해금한다. QA 테스트용 즉시 해금은 개발 전용이다.

분기 대화는 온라인 생성 대사가 아니라 데이터로 작성한 작은 노드 그래프다. ‘도움을 약속한다’와 ‘보상을 먼저 묻는다’는 설명과 반응이 달라지지만 필수 진행을 잠그지 않는다. 답변을 다시 클릭해 보상을 반복 획득하지 않게 quest transitionId와 claim flag를 거래 저장에 포함한다.

드론은 대장장이 구조 보고 후 해금된다. 즉 만든 기능을 이 장에서 실제 진행에 연결한다. 퀘스트 상태는 영구 저장, 대화창 열림과 현재 강조 버튼은 UI 임시 상태다. 구출한 NPC의 마을 출현은 플래그에서 복원하므로 씬마다 NPC를 추가 복제하지 않는다.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
