현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

3D 클릭을 카메라 Ray와 Physics.Raycast로 구현하고 UI 우선순위를 유지해 줘.
먼저 기존 A* waypoint를 XZ로 변환해서 ActorMotor3D로 걷게 해 줘.
이후 현재 AI Navigation과 NavMeshSurface, CalculatePath를 확인해 같은 PathService 계약으로 연결해 줘.
NavMesh는 경로만 계산하고 CharacterController만 위치를 적용해 줘.
NavMeshAgent의 자동 이동이나 Transform 동시 쓰기를 추가하지 마.
반경별 Agent Type, 수집 레이어, SamplePosition 최대 거리, 부분 경로 거부, 실제 몸체 도착을 검사해 줘.
벽 우회, 지도 바깥, 닫힌 문, WASD 취소, UI 클릭을 2D 기준선과 비교해 줘.

적용할 세부 규칙:
경로 서비스는 waypoint와 상태를 반환하고, 실제 위치는 ActorMotor3D 만 변경한다. 기본 게임에서는 NavMeshAgent를 위치 소유자로 추가하지 않는다. 적 회피는 기존의 접근 위치 예약 정책을 재사용한다.

NavMesh 수집 대상은 바닥·벽·문이다. 움직이는 배우·VFX·아이템 그림은 제외한다. Collider와 메시 중 무엇을 수집 기준으로 삼을지 정하고 실제 충돌 형상과 비교한다. 반경 0.35인 플레이어와 더 큰 거구가 같은 작은 Agent Type을 사용하도록 무조건 설정하지 않는다.

클릭점 주변의 샘플 허용 거리와 층 높이를 제한한다. 벽 너머의 먼 지점으로 SamplePosition을 보정하거나 부분 경로를 성공으로 처리하지 않는다. 정적 맵의 베이크로 시작하고, 런타임 랜덤 지형 재생성은 추가한다.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
