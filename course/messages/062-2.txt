현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

OpenAI 이미지 생성으로 2D 게임 아트 후보를 만들어 줘. 연결된 이미지 도구나 승인된 API 중 실제 쓸 수 있는 경로를 확인해 줘. 다른 앱의 결과 파일에 자동 접근할 수 있다고 가정하지 마.
회색 갑옷·청록색 망토·오른손 검의 모험가 기준 그림을 먼저 만들어 줘. 내가 선택한 기준을 유지하며 남쪽 걷기 6포즈와 공격 준비·타격·회수 포즈를 별도로 요청해 줘. 범용 이미지 생성 결과를 정확한 애니메이션으로 단정하지 마.
지원하는 크기로 생성하고 원본을 보존한 뒤 64×64 RGBA 고정 셀, 발 (32,56), 캐릭터 PPU32로 정리해 줘. 투명도는 실제 알파로 검사하고 배경 체크무늬를 투명으로 오인하지 마.
API를 쓰면 키는 안전한 환경에서 읽고 Unity 프로젝트·로그·APK에 넣지 마. 구독과 API 과금이 별도인지 확인하고 첫 요청과 재시도 범위를 승인받아 줘.
파일 생성·수신·정리·Unity 도입을 모두 맡아 줘. 실제 남쪽 동작을 ArtLab2D에서 보여 주고, 채택한 프레임과 수정할 프레임을 구분해 줘. 없는 결과는 만들어졌다고 보고하지 마.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
