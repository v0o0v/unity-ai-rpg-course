현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

PixelLab을 이용해 게임용 픽셀 캐릭터·동작·타일 후보를 만들어 줘. 현재 공식 기능·자동화 경로·계정 권한·사용량 단위를 조사하고 작은 요청의 비용을 먼저 보여 줘. 승인 전에는 결제나 생성하지 마.
회색 갑옷과 청록색 망토, 오른손 검의 모험가를 기준으로 남쪽 그림을 만들고, 내가 승인하면 같은 캐릭터의 걷기 6프레임과 공격 6프레임을 각각 생성해 줘. 다음으로 붉은 갈색 근접병과 석재 타일 3종을 별도 요청해 줘.
방향은 S/W/N/E이며 실제 지원되는 방향·동작 출력부터 사용해 줘. 64×64 RGBA, 캐릭터 PPU32, 발 (32,56), 타일 PPU64로 정리할 계획을 함께 세워 줘.
API/MCP나 승인된 브라우저 자동화로 실제 생성·수신·후처리를 수행해 줘. 사용할 수 없는 경로는 생성했다고 하지 말고 알려 줘. 원본·사용한 설정·실제 비용과 재시도를 남겨 줘.
검 손·발 위치·팔레트·알파·프레임 연속성을 검사하고 ArtLab2D에서 남쪽 걷기와 공격을 보여 줘. 반복 생성 전체 비용을 한 번의 API 가격과 혼동하지 마.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
