현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

Windows 와 Android 빌드를 만드는 프로젝트 전용 Editor 도구를 만들어 줘. GameBuild.BuildWindows 와 GameBuild.BuildAndroidDevelopmentApk처럼 우리가 정의한 메서드를 실제로 등록하고 실행 경로를 확인해 줘. Unity 기본 명령이라고 가정하지 마.
빌드 전 검증과 BuildReport 실패를 실제 실패로 반환하게 해 줘. Windows x86_64는 실행에 필요한 전체 폴더를, Android 는 IL2CPP ARM64 테스트 APK를 만들어 줘.
출시 씬은 Boot·MainMenu·Town·Dungeon01이며 개발용 씬·치트·테스트 메뉴·민감한 로그·Pipeline 제어용 키나 서버는 Player에서 제외해 줘.
서명 정보가 필요한 정식 APK/AAB는 내 서명 설정이 실제로 준비된 경우에만 만들어 줘. 비밀번호는 코드·명령 기록·로그에 넣지 마. 서명 자료가 없으면 테스트 빌드와 정식 배포 준비를 구분해 줘.
빌드의 실제 경로·버전·해시를 기록하고 PC 실행과 연결된 Android 설치를 준비해 줘. 실제 설치·실행 여부는 각각 확인하고 스토어 게시나 외부 업로드는 하지 마.

코드·설정·파일 생성·실행은 네가 맡고, 필요한 화면과 결과를 보여 줘. 수행하지 못한 작업과 필요한 승인·도구 연결은 구분해서 알려 줘.
