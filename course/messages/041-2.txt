현재 프로젝트의 실제 파일과 이미 결정한 규칙을 먼저 확인해 줘. 이름이 다른 기존 구현이 있으면 새로 중복 제작하지 말고 그 구현에 연결해 줘.

9개 노드의 작은 스킬트리 규칙을 만들어 줘.
기존 전투 코드는 보존하고, 스킬 사용 가능 여부를 질의하는 경계를 찾아 교체 준비만 해 줘. 실제 세이브 마이그레이션은 아직 실행하지 마.
정의와 캐릭터 상태를 분리하고 남은 포인트는 level와 rank합으로 계산해 줘. 잘못된 데이터가 음수 포인트로 조용히 통과하지 않게 해 줘.
순환·중복 ID·없는 선행 ID·잘못된 랭크·포인트 초과를 검사하는 테스트를 만들고 실제 실행해 줘.
레벨6에 slash_unlock1/slash_power2/slash_economy1/bolt_unlock1이면 남은0이고 spin은 사용 불가인지 확인해 줘.
기존 SO 원본이나 실제 유저 저장을 수정하지 말고 격리된 테스트 데이터로 검증해 줘.

적용할 세부 규칙:
• ID: slash_unlock / 표시명: 전방 베기 / 최대 랭크: 1 / 요구 레벨: 2 / 선행 노드: 없음 / 랭크당 효과: 베기 사용 가능
• ID: slash_power / 표시명: 날카로운 칼끝 / 최대 랭크: 2 / 요구 레벨: 3 / 선행 노드: slash_unlock 1 / 랭크당 효과: 베기 계수 +0.15
• ID: slash_economy / 표시명: 절제된 베기 / 최대 랭크: 2 / 요구 레벨: 5 / 선행 노드: slash_power 1 / 랭크당 효과: 베기 마나 비용 −1
• ID: bolt_unlock / 표시명: 마력탄 / 최대 랭크: 1 / 요구 레벨: 4 / 선행 노드: 없음 / 랭크당 효과: 마력탄 사용 가능
• ID: bolt_power / 표시명: 응축된 마력 / 최대 랭크: 2 / 요구 레벨: 5 / 선행 노드: bolt_unlock 1 / 랭크당 효과: 마력탄 계수 +0.15
• ID: bolt_economy / 표시명: 마력 절약 / 최대 랭크: 2 / 요구 레벨: 7 / 선행 노드: bolt_power 1 / 랭크당 효과: 마력탄 마나 비용 −1
• ID: spin_unlock / 표시명: 회전 공격 / 최대 랭크: 1 / 요구 레벨: 6 / 선행 노드: 없음 / 랭크당 효과: 회전 공격 사용 가능
• ID: spin_power / 표시명: 회전의 힘 / 최대 랭크: 2 / 요구 레벨: 7 / 선행 노드: spin_unlock 1 / 랭크당 효과: 틱당 계수 +0.05
• ID: spin_stride / 표시명: 움직이는 폭풍 / 최대 랭크: 2 / 요구 레벨: 8 / 선행 노드: spin_power 1 / 랭크당 효과: 회전 중 이동 비율 +0.10

모든 랭크의 가격은 1포인트다. earned = clamp(level-1, 0, 9), spent = sum(ranks), unspent = earned-spent로 계산한다. UI에 남은 포인트를 따로 더하거나 저장하지 않는다. 트리는 순환이 없는 방향 그래프여야 하며, 존재하지 않는 ID·중복 ID·음수 랭크·선행 조건 위반은 오류다.

예: 레벨 6은 5포인트다. 베기 뿌리 1, 힘 2, 절약 1, 마력탄 뿌리 1이면 5를 사용한다. 회전 공격은 레벨 조건을 충족했어도 아직 사용할 수 없다. 이 예를 첫 테스트로 사용한다.
