# AI 개발 참고 자료

harness는 검토 가능한 참고 구현, game_tools는 자산/규칙 보조 도구, expansion_tools는 실제 게임 파일 연결과 확장 데이터의 예입니다. 이 폴더가 학생이 제작한 MyGameHarness를 대신하지 않습니다.

현재 작업 요청을 먼저 읽고 실제 프로젝트·작성본을 조사합니다. 필요한 한 구성요소의 구현·검사를 비교하는 용도로만 사용합니다. 전체 완성본을 복사한 뒤 제작을 완료했다고 보고하지 않습니다.

참고 구현의 명령 이름이나 JSON 형식이 새 작성본과 다를 수 있습니다. 지원 여부를 실제로 확인하고 연결부를 작성합니다. 실행 경로가 없으면 실패를 보고하며 참고본으로 몰래 대체하지 않습니다.

스킬 템플릿은 ../WORK_SKILLS에 있습니다. 사람은 코드나 설정을 편집하지 않습니다. AI가 현재 환경에 맞게 생성·검토·설치하고 실제 로드와 호출을 확인합니다. 스킬 설명서만 존재하는 상태와 실행기가 동작하는 상태를 구분합니다.

참고 문서·예제의 과거 테스트 수나 검사 결과를 사용자 환경의 성공으로 가져오지 않습니다. Python 검사, 실제 Claude, Windows 프로세스, Unity 컴파일, PC/Android 실행, 시청각 판단을 각각 구분합니다.

참고 코드의 검사 실행은 validate_references.py로 연결되어 있습니다. AI가 실행 환경·필요 패키지를 먼저 확인하고 검사를 수행합니다. game_fixtures는 공통 규칙 검사 입력이며 게임의 실제 저장 파일이 아닙니다. 참고 검사의 실패가 있다면 로그를 읽고 원인을 분리하며, 학생에게 환경 변수나 명령을 직접 입력시키지 않습니다.
