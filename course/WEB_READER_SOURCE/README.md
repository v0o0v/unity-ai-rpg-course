# AI 편집용 웹 읽기 계층

학생은 index.html을 읽고 자연어로 작업합니다. 이 폴더를 직접 편집할 과제는 없습니다.

실제 실행본은 루트 index.html입니다. 데이터는 data/lessons.json, data/prompt_guides_v13.json, data/lesson_visuals_v13.json에 있습니다. 문자 범위는 Unicode codepoint이며 읽기 해설은 AI 복사 payload에 합치지 않습니다. v13.js와 v13.css는 최종 HTML에 포함된 실행 코드입니다. 기존 실행 자료는 AI_REFERENCE와 WORK_SKILLS에 보존했습니다.

학생이 만든 하네스를 참고 완성본으로 바꿔치기하지 않습니다. API·명령·계정별 권한은 실제 설치 환경에서 확인합니다.
