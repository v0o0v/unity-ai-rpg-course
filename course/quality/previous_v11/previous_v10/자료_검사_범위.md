# 자료 검사 안내 — 그림으로 이해하는 기술 해설 v10

이 문서는 검증 범위를 알리는 선택 자료입니다. 학습은 `index.html`에서 시작합니다.

## 이번에 추가한 내용

기존 실습 160개와 페이지별 메시지 960개를 보존했습니다. 기술 해설 250개, 자체 제작 SVG 개념도 250개, 28개 해설의 계산·비교 표, 20종의 조작 모형을 23개 해설에 연결했습니다. 한국어·영문·약어 표기별 검색과 본문 링크, 관련 개념 이동, 읽던 실습 단계로 돌아오기, 그림 확대, v9 기록 불러오기를 제공합니다.

250개 중 242개는 원문에서 직접 사용되는 표현과 연결되고, 8개는 다른 개념을 이해하는 보충 해설입니다. 프로젝트별 고유 클래스명·파일명 전체를 사전 항목으로 만들었다는 뜻은 아닙니다. 하네스·스킬 참고 자료와 원문 메시지 836개 파일은 바이트 단위로 보존했습니다.

## 실제 수행한 검사

- 콘텐츠와 자료 연결 5867개 조건: 필수 설명, 관련 해설 대상, 출처 ID, SVG 구조, AI 요청의 표현, 원문 데이터 일치 등을 검사했습니다. 이는 같은 수의 독립적인 게임 테스트가 아닙니다.
- 브라우저 322개 판정: 250개 해설 화면 렌더링, 이미지 디코딩, 검색·필터·링크·읽던 단계와 스크롤 복귀·그림 확대·실제 기록 파일 내보내기와 v9 가져오기·모바일 표시·모형 조작 등을 확인했습니다.
- 실습 요청문 960개: 링크가 삽입된 화면 텍스트와 복사 버튼이 전달하는 원문을 각각 대조했습니다. 페이지별 Markdown의 요청 코드 블록도 원본과 일치합니다.
- A* 모형 200개 지도: 독립 BFS의 최단 거리와 대조하고 벽·비연속 경로를 검사했습니다. 위상 정렬은 5개 작업의 1,024개 순방향 간선 조합과 UI의 순환 반례를 확인했습니다.
- SVG 250개를 실제 브라우저 글꼴로 펼쳐 3,599개 텍스트 그룹의 전체 그림 경계 이탈이 없는지 검사했습니다. 이것만으로 모든 설명의 교육 효과나 모든 글꼴에서의 배치를 보장하지는 않습니다.
- Markdown의 로컬 연결 20031개를 확인했습니다. 최종 ZIP을 다시 열어 파일별 SHA-256을 대조합니다.

## 검사 과정에서 바로잡은 부분

PPU 예시 그림의 크기 비율을 실제 숫자에 비례하도록 맞췄습니다. ‘메시지’를 ‘메시’로 잘못 연결하던 부분을 제외하고 ‘씬’·‘훅’ 같은 한 글자 용어를 처리했습니다. 파일 저장·게임 세이브·하네스 기록·웹 확인 기록의 차이를 보강했습니다. 검사 구성 변경 시 이전 PASS를 재사용하지 않도록 모형을 수정했습니다. 좁은 화면에서 긴 상단 경로와 버튼이 가로로 넘치는 문제를 수정했고, 의존 관계 그림에는 화살표 방향을 명시했습니다.

## 브라우저 검사 환경과 한계

컨테이너의 Chromium을 사용했습니다. 이 환경의 정책으로 `file://` 탐색이 차단되어 정책을 바꾸지 않고 최종 HTML 바이트를 Chromium 문서에 직접 주입하여 검사했습니다. 따라서 사용자의 Windows에서 더블클릭해 여는 경로 자체를 실행했다고 주장하지 않습니다. 해당 문서에서는 네이티브 localStorage 사용이 불가해 저장 불가 안내와 실제 JSON 파일 내보내기·가져오기를 확인했습니다. 파일 출처별 지속 저장과 브라우저 차이는 별도 확인이 필요합니다.

SVG·슬라이더·버튼·격자 모형은 개념 설명용입니다. 실제 Unity·Claude 호출·게임 렌더링·물리 엔진·멀티터치·에셋 다운로드·성능 측정이 아닙니다. 숫자와 규칙은 각 모형에 표시한 가정 안에서만 해석합니다. 열어 보거나 조작해도 실습 완료 체크와 게임 테스트 상태가 바뀌지 않습니다.

이번 작업에서는 Unity·C# 컴파일, 실제 스킬/훅 설치, 유료 모델·아트 생성, Windows/Android 게임 빌드·실기기 완주, 독립 서브에이전트 심사나 실제 초보자의 완주 시험을 수행하지 않았습니다. 기존 AI 작업용 코드가 보존되었음을 확인했으며 해당 코드의 전체 테스트를 이번 설명 추가 작업에서 다시 실행했다는 의미는 아닙니다.
