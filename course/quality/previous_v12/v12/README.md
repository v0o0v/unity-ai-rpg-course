# 자료 검사 안내 — 다크 모드·실습 그림·문장별 이유 v12

실습은 index.html에서 시작합니다. 이 문서는 선택 검증 자료입니다.

## 바뀐 내용

- 실습 수는 256개, 기술 해설은 331개로 유지했습니다. 기존 실습 데이터와 1,536개 실습 요청의 원문을 보존했습니다.
- 모든 실습에 4칸의 기능 흐름·주의 경계·실제 관찰할 장면을 연결했습니다. 개념도 SVG는 256개이며, 이동·전투·퀘스트·소유권·측정 등 24개 도식 유형을 주제에 맞게 사용했습니다. 실습의 네 진행 단계와 그림의 기능 흐름은 별개라고 표시합니다.
- 1,536개 실습 요청, 331개 기술 확인 요청, 시작 화면의 3개 요청에 읽기 설명을 붙였습니다. 총 1,870개 요청에서 12,370개 문장/목록 항목을 다룹니다. 이 중 실습 요청의 항목은 10,928개입니다. 문장 아래의 이유와 굵은 구분 제목은 실제 AI 복사 내용에 들어가지 않습니다.
- 긴 요청의 구분 목록은 펼쳐서 볼 수 있습니다. 원문 보기·이유 숨기기·그림 확대·주의 경계 표시를 추가했습니다. 기술 링크와 읽던 위치 복귀를 유지했습니다.
- 자동·라이트·다크 모드가 있습니다. 기존 기술 그림 331개의 다크 배경용 팔레트를 별도로 만들었으며 이미지를 일괄 반전하지 않습니다. 실습 SVG는 화면 테마 변수를 사용합니다.

## 현재 자료에서 실제 검사한 범위

1. 데이터 검사 14개 묶음: 기존 7개 데이터 블록의 의미상 일치, 모든 요청의 비공백 문자 범위가 순서대로 해설에 연결되는지, 설명 누락 여부, 256개 개념도와 331개 다크 그림의 XML, Markdown 로컬 링크, 세 HTML 시작 경로를 검사했습니다.
2. 전체 콘텐츠 브라우저 검사 33개 묶음: 256개 실습의 네 단계 렌더링, 굵은 요청 문장과 원문 일치, 1,536개 복사 버튼의 원문 일치, 기술 그림 331개 다크 버전 표시/디코딩, 자동·명시적 테마 전환을 확인했습니다. 묶음 수를 게임 테스트 수로 해석하지 않습니다.
3. UI 검사 28개 시나리오: 설명 접기·원문 보기·요구사항 점프·그림 확대·Escape 닫기·기술 설명 왕복·진행 기록 불변·실제 JSON 기록 다운로드와 v11 가져오기·v9/v10/v12 형식 지원·1440px/390px의 밝은/어두운 화면·가로 넘침·확대 중인 그림의 테마 전환 등을 확인했습니다.
4. 256개 실습 SVG의 텍스트가 전체 캔버스 밖으로 나가지 않는지 Chromium 글꼴로 검사했습니다. 이것이 모든 시각 요소의 무겹침이나 교육 효과를 증명하는 것은 아닙니다. 대표 페이지와 모바일 화면은 이미지로 열어 확인했습니다.
5. AI_REFERENCE 194개, WORK_SKILLS 16개, messages 1,216개 파일은 이전 ZIP과 바이트 단위로 대조해 보존했습니다. 실제 요청 수와 파일 수는 저장 형식이 달라 같지 않습니다. 해당 실행 코드의 전체 단위검사를 이번 UI 개정에서 재실행했다는 의미는 아닙니다.
6. 최종 ZIP을 다시 읽어 MANIFEST.json의 파일별 SHA-256과 파일 수를 확인합니다. MANIFEST 자체는 해시 목록에서 제외합니다.

## 수정하며 확인한 문제

문장 해설은 단어 하나보다 실제 요청의 의도를 우선하도록 보완했습니다. 플레이어 안의 ‘레이어’, ‘구분해’ 안의 ‘분해’, 제작 도구의 중복 생성과 아이템 중복 제작 같은 겹침을 구분했습니다. 길 없음과 계산 한도 초과, 요청 스키마와 세이브 이전, Undo와 파일 복구, 목표 프레임과 측정값도 분리했습니다. 대표 문장의 해설을 대조했으며 독립 전문가가 모든 문장을 심사한 결과는 아닙니다.

초기 브라우저 실행에서 그림 확대 대화상자보다 이벤트 연결이 먼저 실행되는 문제를 수정했습니다. 모바일에서는 요구사항 목차를 접을 수 있게 바꿔 문장과 이유를 먼저 읽게 했습니다. 검토 중 테스트 선택자가 실제 돌아가기 버튼과 달랐던 부분을 바로잡았고, 많은 렌더 검사와 화면 캡처를 별도 브라우저 문서로 나눠 검사했습니다. 미완료/중단된 검사 시도의 결과를 최종 통과 수로 합산하지 않았습니다.

## 환경·미검증

컨테이너 Chromium에서 최종 HTML 바이트를 문서에 주입해 검사했습니다. 환경 정책으로 file:// 이동은 차단되어 이를 우회하지 않았습니다. 따라서 사용자의 Windows에서 더블클릭으로 여는 경로나 모든 브라우저를 실행한 것은 아닙니다.

이 출처의 네이티브 localStorage가 허용되지 않아 저장 불가 안내와 실제 기록 파일 다운로드/가져오기를 검사했습니다. 테마 선택 저장·다음 문서 복원은 별도의 명시적 모의 저장소에서 검사했습니다. 실제 로컬 파일 출처의 저장 지속성은 브라우저 환경에 따라 별도 확인이 필요합니다. 선택을 저장하지 못해도 현재 탭에는 테마가 적용되고 안내를 표시합니다.

복사 원문 검사는 버튼이 전달한 문자열을 계측한 검사입니다. 각 원문을 실제 운영체제 클립보드에서 다른 AI 앱에 붙여넣는 실습을 1,536번 수행한 것은 아닙니다.

그림과 조작 모형은 개념 설명용입니다. 실제 Unity 화면·게임 실행·성능 측정·새 아트 서비스 생성 결과가 아닙니다. 스킬/훅 설치, Claude 유료 호출, C# 컴파일, Unity/Quest Editor 실행, Windows/Android 빌드와 실기기, Meshy 생성, 클라우드 게시, 독립 서브에이전트 심사 및 초보자의 완주 시험은 이번 UI 개정에서 수행하지 않았습니다.

웹 확인 체크는 학습 기록이며 게임의 PASS 판정과 다릅니다. 테마·그림·해설을 조작해도 체크가 바뀌지 않습니다. 문장별 이유는 요청이 막으려는 문제를 설명하며 현재 게임 구현이 이미 그 조건을 통과했다는 근거가 아닙니다.
