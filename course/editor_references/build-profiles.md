# Project 창의 Build Profiles — 플랫폼 설정도 자산으로 찾기

Project의 Settings/BuildProfiles 폴더 안에 Android와 iOS 프로필 자산이 있는 모습입니다. 실제 프로젝트에서는 자신의 대상 플랫폼과 경로를 확인합니다.

**공식 문서 기준:** Unity Manual 6.3. Project 창의 일부만 보여 주는 공식 예시입니다. Build Profiles 전체 설정 창의 캡처가 아닙니다.

![Unity 공식 문서의 실제 UI 예시 — 내 프로젝트 실행 결과 아님](https://docs.unity3d.com/6000.3/Documentation/uploads/Main/build-profiles-assets.png)

**출처:** [Unity Technologies · Unity Documentation](https://docs.unity3d.com/6000.3/Documentation/Manual/build-profiles.html) · [원본 이미지](https://docs.unity3d.com/6000.3/Documentation/uploads/Main/build-profiles-assets.png) · [이용 조건](https://unity.com/legal/docs-terms). 원본 수정 없음. 사진은 온라인에서 읽습니다.

## 화면 읽기

### 1. 왼쪽 · 폴더

씬 Hierarchy가 아니라 Project의 자산 폴더입니다. 같은 이름의 파일을 찾았다고 현재 빌드에서 사용 중이라는 뜻은 아닙니다.

### 2. 오른쪽 · 프로필 자산

플랫폼별 프로필을 나누어 관리하는 예시입니다. 이 과정의 기본 대상은 Windows와 Android이므로 화면에 보이는 iOS를 추가할 필요는 없습니다.

### 3. 이어서 확인할 실제 설정

AI가 선택된 프로필·대상·포함 씬·출력 위치를 실제 설치본에서 확인하게 합니다. 아이콘만 보고 APK나 실행 파일이 만들어졌다고 판단하지 않습니다.

## 잠깐 확인하기

프로필 자산이 생겼으면 Android 배포가 끝난 걸까요? 아닙니다. 실제 빌드 결과물, 설치, 실행, 저장·업데이트 검사가 별도로 필요합니다.

## 이 화면이 증명하지 않는 것

이 예시에는 서명 키나 AAB 업로드 화면이 없습니다. 계정·키·비밀번호는 참고 화면을 만들기 위해 공개하거나 채팅에 전달하지 않습니다.

## 내 프로젝트의 실제 창 확인 요청

공식 예시와 실제 프로젝트가 같은지, 캡처 기능이 연결되어 있는지 확인하기 위한 추가 요청입니다. 구현·설정 변경은 자동 승인하지 않습니다.

```text
현재 Windows·Android 빌드에 실제 사용하는 프로필을 찾아 자산 위치와 선택된 대상·포함 씬·출력 경로를 보여 줘. 기존 프로필을 복제하거나 플랫폼을 바꾸지 말고 읽기 전용으로 확인해 줘. 프로필 존재와 실제 빌드·기기 실행 성공을 구분하고 서명 키·비밀번호는 캡처하거나 출력하지 마.
화면을 보여 줄 수 있는 도구가 있다면 실제 창을 캡처해 새 파일로 남기고 파일 경로·프로젝트·버전·현재 상태를 함께 알려 줘. 민감정보가 보이면 먼저 안전한 화면으로 준비해 줘. 캡처 도구가 없으면 연결이 없다고 설명하고 AI가 그린 가짜 Editor 화면으로 대신하지 마. 코드를 직접 입력하도록 요구하지 마.
```

기존 실습과 필수 검사는 유지합니다. 창 캡처가 없으면 없다고 기록하고 다른 그림으로 실행 결과를 만들어 채우지 않습니다.
