# 웹 실습서 시작하기

index.html을 브라우저에서 엽니다. 아직 로컬 AI가 없다면 시작 화면의 **AI 작업창이 아직 없다면 여기서 시작하세요**를 읽습니다. 앱 설치·로그인·권한 선택은 처음 한 번 사람이 하고, 이후 코드·명령·설정·게임 파일 생성은 AI가 맡습니다.

## 한 페이지의 진행
목표·시작 상태를 확인하고 1 준비→2 만들기→3 직접 확인→4 기록 순서로 한 메시지씩 보냅니다. **현재 메시지** 버튼으로 바로 이동할 수 있습니다. **그림**, **구체적인 예**, **값·규칙**을 필요한 때 펼쳐 보세요. 굵은 문장은 실제 요청이고 바로 아래 이유는 읽기 설명입니다. 복사는 요청 원문만 전달합니다.

## 결과가 다를 때
현재 페이지의 **막혔어요**와 **막힘 진단**을 사용합니다. 어떤 시작 상태에서 무엇을 눌렀고 어떻게 달랐는지 말하면 AI가 로그·연결·코드를 조사해 수정합니다. 직접 구현 파일을 편집할 필요는 없습니다.

## 화면과 기록
상단에서 자동·라이트·다크를 선택합니다. v9~v12 확인 기록을 가져올 수 있습니다. 기록은 사람의 학습 체크이지 게임 테스트 통과가 아닙니다. 바뀐 요청이 있는 페이지는 현재 조건을 다시 비교하세요. 브라우저 저장이 막히면 **내 기록 저장**으로 기록을 보존합니다.

## 자료의 범위
AI_REFERENCE와 WORK_SKILLS는 AI가 참고할 자료입니다. 학생이 직접 코드를 입력하는 과제가 아닙니다. 실제 게임·Claude·Unity·기기 연결은 자신의 환경에서 진행합니다. 독립 비평가 심사는 로컬 연결 문제로 아직 수행하지 못했습니다. 현재 검토 내역은 review/검토보고서.md, 실제 검사는 자료_검사_범위.md에서 확인할 수 있습니다.


## 실제 Unity Editor 화면 참고
관련 실습에서 “실제 Unity Editor 화면”을 펼치세요. 원본 이미지는 인터넷 연결 후 버튼을 눌러 읽습니다. 오프라인 이미지 묶음이 아닙니다. [화면 안내](Editor_화면_안내.md)에 출처·버전·이용 조건이 있습니다. 원래 실습 요청과 확인 기록 형식은 유지합니다.
