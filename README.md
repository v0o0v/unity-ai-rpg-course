# Unity AI RPG Course

Unity CLI와 AI로 게임을 만드는 **수강생용 웹 실습서**입니다. 현재 기준은 v14: 256개 실습, 331개 기술 해설, 다크 모드, 시각 자료, 요구사항별 프롬프트 해설과 Unity Editor 화면 참고입니다.

## 먼저 알아둘 현재 상태

**이 묶음은 GitHub 업로드 준비본입니다. 이 파일을 만든 ChatGPT 세션에서는 업로드가 성공하지 않았습니다.** GitHub 파일 생성 요청이 403 `Resource not accessible by integration`으로 거부됐습니다. 로컬 PC의 연결도 사용할 수 없었습니다. 저장소에 이미 커밋된 자료를 받은 것처럼 판단하지 마세요.

실제 업로드 여부는 원격 `v0o0v/unity-ai-rpg-course`의 커밋과 파일로 다시 확인합니다. `TRANSFER_STATUS.json`은 준비 시점의 기록입니다.

## 실습서 읽기

`course/index.html`을 브라우저에서 엽니다. `course/시작하기.md`에서 화면 사용법을 볼 수 있습니다. Editor 참고 사진은 요청할 때 공식 서버에서 불러오기 때문에 인터넷이 필요합니다. 나머지 해설·개념도는 묶음 안에 포함되어 있습니다.

## 다른 PC의 Codex에서 이어가기

이 폴더를 로컬 Codex 작업 폴더로 열고 아래 요청을 보내세요.

> AGENTS.md, HANDOFF.md, START_CODEX.md를 읽고 준비된 전체 자료를 v0o0v/unity-ai-rpg-course에 업로드해 줘. 먼저 원격 저장소와 로그인 계정, 현재 파일을 확인해 줘. 기존 원격 내용이 있으면 덮어쓰지 말고 차이를 보여 줘. 검증·Git 설정·커밋·push는 네가 수행하고 인증이 필요하면 공식 로그인 화면만 안내해 줘. 비밀번호나 토큰을 채팅에 받지 마. 강의 내용을 바꾸거나 GitHub Pages를 켜지는 마. 원격 커밋과 대표 파일까지 확인한 뒤 실제 성공 여부를 알려 줘.

학생이 코드를 직접 입력하는 과제나 수동 터미널 명령을 요구하지 않습니다. 다만 계정 로그인·권한 승인·다운로드한 자료의 접근 허용은 사람이 합니다.

## 자료 구조

- `course/`: 원본 v14 전체 자료 3,369개를 변경 없이 보존
- `HANDOFF.md`: 목표·현재 구조·중요한 결정·남은 검증
- `START_CODEX.md`: 업로드와 작업 재개의 구체적인 요청
- `AGENTS.md`: 이 저장소를 다루는 AI의 작업 규칙
- `tools/verify_handoff.py`: AI가 실행할 원본 무결성 검사
- `IMPORT_MANIFEST.json`: 가져온 원본의 파일 목록과 해시
- `PUBLICATION_CHECK.md`: 공개 준비 시 수행한 검사와 한계
- `NOTICE.md`: 기존 출처·권리 안내 보존 원칙

## 교육 목표

기초 Unity 실습 경험자가 자연어로 요구하고 AI와 Unity CLI를 연결하여 게임을 처음부터 끝까지 제작·진단·수정할 수 있게 합니다. 이어서 자기 하네스를 AI로 만들고 스킬·훅을 통해 개발에 활용합니다.

| 범위 | 내용 |
|---|---|
|1~80|2D 싱글플레이 RPG|
|81~104|동일 규칙과 데이터를 사용하는 3D 버전|
|105~128|빈 폴더에서 AI로 역할 기반 하네스 제작|
|129~160|자기 하네스로 기존 2D 게임 확장|
|161~256|독립적인 이야기형 3D RPG, AI 퀘스트 편집기, 제작 도구, 성능 튜닝과 출시 후보 검증|

이 저장소는 완성된 Unity 프로젝트·APK·유료 생성 자산을 제공한다는 뜻이 아닙니다. 독립 심사와 실제 Claude·Unity·Android·Meshy·실제 수강생 완주 검증은 완료되지 않았습니다. 기존 검토 후보 상태를 유지합니다.

공개 저장소를 만든다는 승인과 GitHub Pages·외부 스토어 게시·유료 서비스 실행 승인은 별개입니다. 여기에는 자동 게시 워크플로를 추가하지 않았습니다.
